Setup IRC on Thunderbird with a server password and SASL

When adding an IRC chat account to Mozilla Thunderbird, it asks for a nickname and a password. Some IRC servers use two passwords; an account password (SASL) and a server password. To register an account, you need to first get into the server using the server password.

Thunderbird has only one password box and it is for the account password. This seems to make everything impossible, however there is a hidden way to add the server password to the Thunderbird config. While I recommend just using a proper IRC client, these steps seem to work for me.

First, go to settings -> chat -> styling and set the theme to 'simple' (important).

Then, go to settings -> account settings (at the bottom) -> add account -> chat account -> IRC

Enter the username you want and set Server to the server domain you're connecting to. On the next screen, leave password blank. Leave everything on the screen after untouched, unless the server is specifically on a different port.

When you complete adding your account, it will try to connect and it will fail. Thunderbird is trying to log in with your unregistered account and never sends the actual server password. First you need to set the server password in the config.

Go to settings -> general -> config editor (scroll all the way down)

The account you've just created will be called account1 in the config. In the search, type messenger.account.account1.options.serverPassword. Switch this to String, then press the add button. Type in the server's password and click save.

Now you can connect. You should be in the server, but everything will be blank. Click on 'Join chat' and put in general (or whatever channel). In the chat box, type the command

/msg NickServ REGISTER <yourpassword>

and your account will register. You can now disconnect (in the top right you can click 'show accounts'), go to properties, and put your own password in. You now connect to the server with your account and can chat and so on. Once you're back in, you can use /list to show all channels.

As I said, a dedicated IRC client is probably much better. But it's nice having one less program to download. Here's a couple resources for more on IRC:
